# Frontier Bingo — California outreach dashboard

23 hall websites, 23 individual emails, and 23 improvement plans. Includes the original three halls and 20 new California prospects. The new prospects have published business contact emails; Hawaiian Gardens still needs a recipient.

## Update GitHub

1. Extract Frontier-Bingo-GitHub.zip.
2. Upload its **contents** to the root of AndrewRinglein/F-marketing. Replace the existing index.html, hall pages, and plans; include all 23 hall folders and .nojekyll. Do not upload the ZIP as the website.
3. Keep the existing GitHub Pages branch/root settings. No install or build is required.
4. Open [the dashboard](https://andrewringlein.github.io/F-marketing/) after Pages finishes publishing.

The public link stays the same. The 20 new links begin working after this upload. Existing hall links remain unchanged.

## Use the dashboard

Search by hall, city or charity, or filter by region. Each hall has a checked selection box, its prepared email, its website, its plan and source notes. There are no repeated Send Email buttons inside the hall cards.

**Send All Emails** opens a queue of separate personalized drafts in your email app. Finish sending there. You can also copy formatted or plain-text emails and download an HTML email from the outbox. Enter your sender name and business postal address first. Recipient addresses can be edited in each email card. Signature and recipient changes are saved only in that browser.

## What varies

The new websites use six different compositions: a bold event poster, an editorial page, a schedule-first page, a club page, a charity-focused page, and a ticket-style page. Headlines, packages, featured offers, rewards, schedules and outreach recommendations vary by hall.

Text signup is a leading recommendation where it was not visible. Existing texting, rewards and presales are acknowledged. Examples include fixing Park Place's reservation button, simplifying Milpitas's existing ordering path, and making Broadway's app-based reservation path easier to use. The 42% six-month presale result supplied by Frontier appears only in the two original Hawaiian Gardens and McAlister emails.

## Research and prototype behavior

Research date: September 10, 2026. Each plan links to the reviewed public pages and contact evidence. This is a prospect list, not a ranking by hall size. Some programs run weekly, others monthly. Source inconsistencies and proposed details are recorded in the plans' setup notes.

Website concepts include proposed offers, loyalty benefits and package choices. No actual card payments, bookings, text subscriptions or loyalty accounts are created by the preview flows. Published ordering services are linked where verified. The design does not transfer its selected cart to an external provider. New promotions, final schedules and service connections need operator setup before a player launch.

The package is static and has no backend. Publishing it makes the dashboard, drafts, and public-contact research accessible at the Pages address. No emails have been sent by this work.
