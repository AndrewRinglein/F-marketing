# Frontier Bingo — California outreach dashboard

24 hall websites, 24 first emails, 24 competition follow-ups, 24 improvement plans, and 24 personalized competition maps with separate hall-by-hall comparison pages. The new prospects have published business contact emails; Hawaiian Gardens still needs a recipient.

## Update GitHub

1. Extract Frontier-Bingo-GitHub.zip.
2. Upload its **contents** to the root of AndrewRinglein/F-marketing. Replace the existing index.html and hall folders; include competition-assets, all 24 hall folders and .nojekyll. Each hall folder now contains index.html, plan.html, competition.html and competitors.html. Do not upload the ZIP as the website.
3. Keep the existing GitHub Pages branch/root settings. No install or build is required.
4. Open [the dashboard](https://andrewringlein.github.io/F-marketing/) after Pages finishes publishing.

The public dashboard link stays the same. The new competition links begin working after this upload. Existing hall links remain unchanged.

## Use the dashboard

Search by hall, city or charity, or filter by region. Each hall has a checked selection box, its prepared email, its website, its plan and source notes. There are no repeated Send Email buttons inside the hall cards.

Choose **First email · Website & ideas** or **Follow-up · Competition analysis** in the outbox. Copying and downloading use the selected email. Live sending schedules the introduction and its competition follow-up together. Every follow-up has its own hall-centered map link and a link to the full competitor directory.

The competition map uses the supplied Bingo Scout directory plus current website reviews. It starts at the recipient's hall, with a 50-mile straight-line radius. Change the distance or game day, search a hall, and open its details. The separate comparison page includes nearby halls' schedules, buy-ins, offers, text signup, advance ordering, rewards and sources. Current website findings are distinguished from older Scout listings. Shared days are not proof of overlapping audiences, and no competitor revenue or audience percentages are estimated. Several programs may share one physical venue. Previously excluded outreach organizations appear only as competitors where relevant; the recipient list has not expanded.

Map pins and page assets are bundled. The street map loads standard OpenStreetMap tiles over the internet, with dark styling applied in the page. No API key is required. Normal interactive viewing follows the OpenStreetMap tile usage policy (https://operations.osmfoundation.org/policies/tiles/); there is no bulk download or offline tile cache. The hall directory stays usable if the map service is unavailable.

**Send All Emails** opens the private sending console at send.html, retaining your selected halls. Sign in as an approved operator to use the Instantly connection. Sending stays paused until the provider, verified contacts, signature and inbox test are configured. You can also copy formatted or plain-text emails and download an HTML email from the outbox. Enter your sender name and business postal address first. Recipient addresses can be edited in each email card. These preview edits are saved only in that browser. The private sending backend has its own approved content, verified recipients and signature; preview edits do not silently change live emails.

## What varies

The new websites use six different compositions: a bold event poster, an editorial page, a schedule-first page, a club page, a charity-focused page, and a ticket-style page. Headlines, packages, featured offers, rewards, schedules and outreach recommendations vary by hall.

Text signup is a leading recommendation where it was not visible. Existing texting, rewards and presales are acknowledged. Examples include fixing Park Place's reservation button, simplifying Milpitas's existing ordering path, and making Broadway's app-based reservation path easier to use. The 42% six-month presale result supplied by Frontier appears only in the two original Hawaiian Gardens and McAlister emails.

## Research and prototype behavior

Research date: September 10, 2026. Each plan links to the reviewed public pages and contact evidence. This is a prospect list, not a ranking by hall size. Some programs run weekly, others monthly. Source inconsistencies and proposed details are recorded in the plans' setup notes.

Website concepts include proposed offers, loyalty benefits and package choices. No actual card payments, bookings, text subscriptions or loyalty accounts are created by the preview flows. Published ordering services are linked where verified. The design does not transfer its selected cart to an external provider. New promotions, final schedules and service connections need operator setup before a player launch.

The public website package is static. The private sending console connects to the separately deployed Supabase backend, with Instantly credentials stored only on the server. Publishing it makes the dashboard, drafts, and public-contact research accessible at the Pages address. No emails have been sent by this work.
