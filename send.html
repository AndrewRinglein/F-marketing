Launch setup

  1. Open an Instantly account. Choose Email Outreach → Hyper Growth for API access and status notifications. View plans
  2. Add two pre-warmed domain bundles. Ten Google mailboxes in total. Set the sender display name to your real name and Frontier Gaming Systems, and forward the domains to frontiergamingsystems.com.
  3. Connect the account privately. Store the Instantly API key in the backend’s secrets, then connect the campaign and its status notifications. Never put this key in GitHub.
  4. Test one complete sequence in our own inboxes. Check the website links, signature, reply handling and unsubscribe link.
  5. Verify the recipient list and start gradually. Begin with five outreach emails per mailbox per day, then increase after checking results. Follow-ups count toward the same limit.

Estimated provider cost: $197/month + $30/year for two domains, before tax, email verification and any backend charges. Mailbox inventory and prices are confirmed at checkout. The pre-warmed domains remain owned by Instantly.
